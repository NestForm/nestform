== Description ==

Nestform is a focused form builder for lead capture, feedback, and interactive flows — not a Contact Form 7 clone.

**Free** ($0):

* Up to 5 forms with templates
* Drag-and-drop builder, conditional logic, file uploads
* Entries inbox, CSV export, email notifications
* reCAPTCHA, honeypot, rate limiting
* Gutenberg block, shortcode, basic analytics

**Pro** ($9.99/mo or $89.99/yr — single site):

* Unlimited forms, multi-step flows, branch rules
* Quizzes & surveys with scoring and result bands
* HTML email designer, PDF attachments, webhooks, automations
* Advanced fields (rating, signature, NPS, scale, ranking, matrix)
* Calculated fields, repeaters, advanced analytics, lead insights

**Agency** ($29.99/mo or $269.99/yr — up to 5 client sites):

* Everything in Pro
* Priority support & onboarding
* Agency license for client sites
* White-label ready workflows and early access to integrations

Nestform Pro is a separate add-on (`nestform-pro`) sold via [Freemius](https://freemius.com). Compare plans in **Forms → Upgrade** or **Docs**.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/nestform/` or install from the WordPress plugins screen.
2. Activate **Nestform** through the **Plugins** menu.
3. Open **Forms** in the admin menu to create your first form.
4. Embed with the Gutenberg block or shortcode `[nestform id="123"]`.
5. Read **Forms → Docs** for a guided tour of the builder, entries, Pro, and licensing.

For Pro features, purchase Nestform Pro and install the premium add-on — see **Forms → Upgrade** or **Account** after checkout.

== Frequently Asked Questions ==

= Is Nestform Pro included in this download? =

No. This is the free plugin. Nestform Pro is a separate premium add-on unlocked with a Freemius license.

= How many forms can I create on the free plan? =

Up to 5 published or draft forms. Pro and Agency remove the limit.

= What is the difference between Pro and Agency? =

Pro unlocks all premium features on one WordPress site. Agency includes everything in Pro plus a multi-site license (up to 5 client sites), priority support, and team-oriented perks. See **Forms → Docs** or **Upgrade** for the full comparison.

= Does Nestform store submissions? =

Yes. Submissions appear under **Forms → Entries** with export to CSV.

== External services ==

This plugin can connect to optional third-party services configured by the site administrator:

* **Google reCAPTCHA** — spam protection when enabled under Forms → Integrations.
* **Freemius** — licensing and checkout for Nestform Pro when product credentials are configured in the plugin (see the plugin repository docs for setup).
